## 002. カテゴリごとの予算は専用のコレクションに月ごとに持つ

- 日付: 2026-11-22
- 対象: `books/{鍵}/catBudgets`・firestore.rules・「月の予算」の画面・「今月」のカテゴリ別

### 決定

カテゴリごとの予算は `catBudgets/{YYYY-MM_カテゴリID}` に `{amount}` で持つ。その月の額は、月全体の予算と同じく「その月か、それより前で一番新しい月の値」。0 は「決めていない」。

### 背景

「カテゴリ別の予算を設定したい。超えたら赤にしたい」という依頼。月全体の予算は「変えると今月から先に効き、過去の月は変わらない」作りなので、カテゴリ側も同じ意味に揃えたかった。fable-advisor（opus）と壁打ちして決めた。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| カテゴリの文書に `budget` を足す | 改名・並べ替えは `{name, order, hidden}` を丸ごと書くので、予算が消える。過去の月も今の額で判定される。最初からあるカテゴリは、予算を付けた時点の名前が保存先に固定される |
| `budgets/{YYYY-MM}` に map で持つ | rules が map の中身を検査できない（001 と同じ理由） |

### 影響範囲

- rules に `catBudgets` の match を足した。アプリより先に rules を出す。逆だと保存が断られる。
- 古い版を開いたままの端末は `catBudgets` に触らないので、予算は消えない。
- 文書名はカテゴリ ID が英数字だけという前提（最初の7種と自動 ID）。`tests/rules.test.ts` がアプリ側の読み分けと rules の正規表現を突き合わせる。

### 検証

- `tests/model.test.ts`（引き継ぎ・0 の扱い・文書名）、`tests/app.test.tsx`（赤くする・残りの知らせ・変わった分だけ保存）、`tests/rules.test.ts`。
